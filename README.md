# PicPay Simplificado

Implementação do desafio PicPay utilizando Java e Spring Boot.

## Tecnologias
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
- Maven
- Lombok
- Postman

## Funcionalidades
- Cadastro de usuários
- Consulta de usuários
- Transferências entre usuários
- Validações de saldo
- Validação de tipo de usuário
- Serviço externo de autorização
- Tratamento global de exceções
- DTOs para Request e Response

### Users
POST /users
GET /users
GET /users/{id}
PUT /users/{id}
DELETE /users/{id}

### Transactions
POST /transactions
